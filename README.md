# GSB Bugfix Task
## 题面
刷怪预算和悬赏契约打通以后，野外经济开始崩：导演脚本不看预算，一波怪把整周额度刷光，后面七天只剩空场；预算随时间恢复但没有上限，挂机一小时回来能一次刷五十只；怪物还没死，契约进度就提前加；玩家在别的区域杀同名怪，契约也涨；一份契约能重复签，交付时领两份钱；过期契约还能交，奖励照发；击杀掉落的材料没有进背包，契约奖励里的物品也没发；怪物编号重复，两只怪共用一条命；清怪不扣存活数量，界面上怪物越堆越多；同一份契约连点两次交付，金币翻倍。spawn_contract.py 的 SpawnContract 管区域预算、刷怪导演、悬赏契约和掉落。区域配置有初始预算、预算上限、每秒恢复量和固定波次；tick 按经过时间补充预算并封顶，时间倒退要拒绝；direct 按波次整波生成，单位编号由区域名加递增序号拼成，预算不够整波拒绝、不允许只刷一半，生成后扣预算并登记存活单位。契约带区域、怪物、击杀数、金币、物品和截止时间；签契约校验玩家与契约存在、同一契约不能重复签、超过截止时间不能签，每名玩家同时持有的契约有上限。slay 只能结算本区域存活的单位，移除单位、把怪物掉落放进玩家背包，并只推进该玩家已签、区域与怪物都匹配且仍在进行中的契约进度，进度封顶不溢出。交付要求进度达标且在截止前，发放金币和物品并把契约置为完成；未达标、已交付、已过期都拒绝。state 返回各区域预算与存活单位、每名玩家的契约进度与状态、金币和背包，全部是副本。

## 运行方式
```bash
python -m pytest tests -q
```
