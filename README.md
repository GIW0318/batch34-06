# GSB Bugfix Task
## 题面
宠物竞技场第二赛季开打后，客服收到的截图一张比一张离谱：匹配只看等级，三十级的高攻宠连着撞上满防御的龟宠，新人十连败；同一个主人的两只宠物被配到一起，自己打自己；排队里的宠物下线了还挂在队列，别人永远配不上；回合顺序按进场次序走，速度属性完全没用；属性克制写在面板上却不参与伤害，火系打草系和打水系一个数；伤害算成负数时倒着回血；血量打空后还多打了两回合才判负；结算把胜利记在宠物身上，主人拿不到赛季奖励；奖励按最后一场胜负发，赛季榜第一反而没有；重复点结算，同一份奖励发了两遍；赛季结束不清零，新赛季开局就带着上赛季的积分。pet_arena.py 的 PetArena 负责排队、撮合、对战和赛季结算。宠物数据带主人、属性、血量、攻击、防御和速度，战力按这些数值算出来；入队只能由主人操作，同一只宠物不能重复排队，队列按入队时间先后。撮合取请求者最早入队的宠物，找队列里最早的、主人不同且战力差不超过阈值的对手，配成一场并从队列摘除，找不到就返回空；同一主人的宠物永远不互相匹配。对战在副本上模拟，速度高者先手，速度相同按宠物编号升序；伤害等于攻击乘属性倍率再减防御，至少扣一点，属性按火克自然、自然克水、水克火的环算倍率；单场上限为固定回合数，打满时按剩余血量比例、再按速度、最后按编号判胜。对战后胜者加分、败者扣分并累计场次；赛季结算按积分、胜场、编号排序，把配置里的奖励发给排名靠前宠物所属的主人，同一主人多只宠物上榜要合并，结算后积分与场次归零、赛季编号加一；没有对战记录的赛季不能结算。state 给出宠物面板、队列、历史对局和赛季信息，返回前做深拷贝。

## 运行方式
```bash
python -m pytest tests -q
```
